# Changelog

All notable user-facing changes are listed here. Detailed notes for older releases: [docs/releases/](docs/releases/).

## Unreleased

- Для Cloudflare Proxy разделены TLS SNI и HTTP WebSocket Host: TLS использует базовый домен, а Host сохраняет kwsN.<domain> для выбора DC и путь /apiws. Изменение применяется к MTProto, SOCKS5 и встроенной диагностике; Direct WS и Cloudflare Worker не затронуты (#156, PR #157). Работоспособность подтверждена владельцем на Android в одной тестовой среде; совместимость со всеми операторами не заявляется.

## 1.11.8 — 2026-11-12
- При попытке запуска на занятом локальном порту приложение показывает короткое сообщение о занятом порту и совет изменить настройки; для SOCKS5 добавлена проверка доступности порта до вызова native runtime (#148).
- Плитка Quick Settings использует согласованное состояние локального frontend для цвета и действий: при расхождении isRunning и serviceStatus она временно недоступна и не посылает ошибочный STOP; при запуске/остановке учитываются переходные состояния и задержанные события (#146). Проверка SystemUI Xiaomi/Android 14 остаётся частью приёмки.
- Кнопка «Скачать и установить» в стартовом popup теперь запускает проверяемую загрузку без перехода на экран «Обновления». При наличии разрешения системный установщик открывается напрямую; при отсутствии разрешения или ошибке используется экран обновлений. Добавлены уведомление о загрузке/готовности, отмена через уведомление и безопасное продолжение при возвращении из фонового режима (#139).
- При первом обновлении TgWsProxy самостоятельно открывает системную настройку разрешения установки из этого источника после подтверждения установки APK. После выдачи разрешения продолжается установка уже проверенного файла; отказ не вызывает циклического открытия настроек (#139).
- Исправлены повторные проверки GitHub Releases при открытии экрана обновлений и каждом перезапуске приложения: результат стартовой проверки сохраняется на 6 часов, ошибка связи — с повтором не чаще раза в 5 минут. Ручная проверка всегда выполняет новый запрос (#139).
- Подписанная debug-сборка 1.11.7-debug больше не предлагает установленный релиз v1.11.7 с тем же номером версии; новое предложение появляется только при наличии более новой версии. Для стартового popup добавлен отдельный UI-тест (#139).
- В экран «Обновления» добавлен компактный интерфейс v6: закреплённая нижняя кнопка, раскрываемое «Что нового», ссылка на официальный релиз и переключатель напоминаний. При запуске приложение может предложить новую версию; «Позже» откладывает предложение на 24 часа, уведомления можно отключить (#139).
- Добавлена потоковая загрузка официального ARM64 APK в приватный кэш, проверка SHA-256 и сертификата подписи, packageName, versionCode и совместимости Android. Установка передаётся системному Android Package Installer после согласия пользователя. Устройство Xiaomi проверено владельцем в рамках подготовки релиза; подробные логи отдельных сценариев не предоставлены.
