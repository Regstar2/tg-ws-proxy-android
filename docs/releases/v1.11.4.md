# v1.11.4 — Исправления Quick Settings, уведомлений и инструкции

**Русский** · [English](v1.11.4_EN.md)

## О релизе

`v1.11.4` — планируемое совместимое стабильное исправляющее обновление TgWsProxy Android для Android 8.0+ / ARM64 (`arm64-v8a`). Метаданные кандидатной версии: `versionName 1.11.4`, `versionCode 60`. Изменения направлены на поведение системной плитки, foreground-уведомлений и первоначальной инструкции. Маршрутизация Telegram и форматы пользовательских настроек не меняются; отдельная миграция не требуется.

## Главное

- Долгое нажатие на плитку TgWsProxy направляется в главное окно приложения; фактическое поведение зависит от реализации Android SystemUI и требует отдельной проверки на Xiaomi/HyperOS.
- Уведомление работающего прокси перестаёт публиковать неизменившееся содержимое при каждом обновлении статистики. На Xiaomi / Android 14 проверена работа вместе с VPN-уведомлением скорости.
- Опция «Не показывать снова» сохраняется даже при пропуске инструкции или закрытии диалога, а инструкция остаётся доступна через справку.

## Изменения

### Исправлено

- **Quick Settings:** добавлен системный обработчик `QS_TILE_PREFERENCES` для открытия `MainActivity` при долгом нажатии. Повторный запуск уже открытого приложения возвращает на главный экран, не переключая прокси; короткое нажатие не изменено ([#114](https://github.com/Regstar2/tg-ws-proxy-android/issues/114), [PR #116](https://github.com/Regstar2/tg-ws-proxy-android/pull/116)).
- **Foreground-уведомления:** повторная публикация одинакового видимого содержимого подавляется, изменившиеся периодические данные ограничены одним обновлением за три секунды, время создания уведомления остаётся постоянным на протяжении сессии. Жизненный цикл и действия уведомления сохранены ([#115](https://github.com/Regstar2/tg-ws-proxy-android/issues/115), [PR #117](https://github.com/Regstar2/tg-ws-proxy-android/pull/117)).
- **Первоначальная инструкция:** выбор «Не показывать снова» сохраняется после «Готово», «Пропустить» и системного закрытия. Параметр `onboarding_completed` совместим с прежними установками; справка позволяет открыть инструкцию вручную ([#118](https://github.com/Regstar2/tg-ws-proxy-android/issues/118), [PR #119](https://github.com/Regstar2/tg-ws-proxy-android/pull/119)).

## Установка и обновление

После публикации скачайте `TgWsProxy-Android-v1.11.4-arm64-v8a.apk` со [страницы релиза](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.4). Требования: Android 8.0+ и ARM64.

Установите APK поверх предыдущей **официальной** версии, не удаляя приложение: для сохранения настроек подпись должна совпадать. При чистой установке настройте MTProto-прокси в приложении и при необходимости добавьте плитку через редактор быстрых настроек Android. Обновление автоматически не устанавливается: экран обновлений открывает официальный GitHub Release. Возврат на версию с меньшим `versionCode` без удаления данных Android не гарантирует.

Плитка управляет только локальным сервисом: она не изменяет настройки Telegram и не создаёт системный VPN.

## Известные проблемы

- На Xiaomi/HyperOS долгий тап по плитке зависит от SystemUI; необходим фактический device smoke по [чек-листу](../testing/quick-settings-long-press.md). Автоматическая проверка manifest не доказывает, что OEM откроет приложение.
- Flowseal Legacy WebSocket остаётся экспериментальным: в сетях с ограничениями долгих соединений Cloudflare могут не работать сообщения и медиа. HTTPS Chunk Relay зависит от Durable Objects и может быть медленнее прямого подключения.
- Для запуска из плитки необходима ранее успешно сохранённая конфигурация; после изменения сети, маршрута или AWG-профиля может потребоваться запуск из приложения. Полная OEM-матрица не проверена.

## Артефакты

После успешного выполнения release workflow ожидаются **ровно два** файла:

- `TgWsProxy-Android-v1.11.4-arm64-v8a.apk` — подписанная сборка Android 8.0+ / ARM64.
- `TgWsProxy-Android-v1.11.4-arm64-v8a.apk.sha256` — SHA-256 фактически собранного APK.

Фактические размер APK и checksum определяются **после** публикации, поэтому в исходной документации не приводятся.
