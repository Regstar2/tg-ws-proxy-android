# v1.11.1 — автозапуск прокси после загрузки Android

**Русский** · [English](v1.11.1_EN.md)

## О релизе

`v1.11.1` — стабильный patch-релиз TgWsProxy Android для Android 8.0+ / `arm64-v8a`.

Метаданные: `versionName 1.11.1`, `versionCode 57`.

Главное изменение — опциональный автозапуск существующего локального proxy runtime после завершения загрузки Android. Настройка выключена по умолчанию и не меняет текущее поведение приложения, пока пользователь явно её не включит.

## Автозапуск

В **Настройки → Приложение → Служба** добавлен переключатель **«Автозапуск при включении устройства»**.

Когда он включён:

1. Android отправляет приложению `BOOT_COMPLETED`;
2. TgWsProxy проверяет сохранённую настройку и последнюю конфигурацию прокси;
3. запускается существующий `ProxyService.ACTION_START`;
4. используется тот же foreground notification path, что и при обычном ручном запуске;
5. Activity не открывается автоматически.

Используются уже существующие сохранённые параметры: локальный порт, runtime config/IPs, pool size, выбранный frontend и связанные настройки маршрутизации.

Для SOCKS5 пустая/невалидная runtime-конфигурация не приводит к бессмысленному foreground service. Frontend, которому `last_runtime_ips` не требуется, не блокируется искусственно.

Ручная остановка прокси не выключает настройку автозапуска: она отвечает только за поведение при следующей загрузке системы.

## Совместимость с OEM-прошивками

Некоторые Android-прошивки дополнительно ограничивают boot/background autostart.

Реальный reboot smoke был подтверждён на Xiaomi/HyperOS после включения отдельного системного разрешения фонового автозапуска для TgWsProxy. Приложение не пытается обходить OEM-ограничения скрытыми механизмами.

## Диагностика

Добавлены privacy-safe события `BOOT_*` для:

- получения `BOOT_COMPLETED`;
- отключённого автозапуска;
- успешной отправки `ACTION_START`;
- пропуска из-за невалидного сохранённого состояния;
- уже запущенного runtime;
- ошибки старта.

Секреты, WARP/AWG ключи, токены и приватная runtime-конфигурация в эти события не записываются.

## Тесты

Добавлены unit-тесты для:

- значения по умолчанию `false`;
- сохранения/чтения настройки;
- disabled → skip;
- enabled + valid config → start;
- enabled + invalid SOCKS5 config → skip;
- MTProto/frontend без обязательного runtime IP config;
- повторной доставки boot события;
- сохранения и загрузки общей стартовой конфигурации.

Реальный reboot/device smoke подтверждён перед подготовкой релиза.

## Установка и обновление

Скачайте:

`TgWsProxy-Android-v1.11.1-arm64-v8a.apk`

Требования: Android 8.0+ и `arm64-v8a`.

Официальный APK использует ту же release-подпись и предназначен для обновления поверх `v1.11.0` без удаления приложения и потери app-private настроек.
