# v1.11.3 — Quick Settings control for the local proxy

[Русский](v1.11.3.md) · **English**

## About this release

`v1.11.3` is a compatible TgWsProxy Android release for Android 8.0+ (`arm64-v8a`). It adds an Android Quick Settings tile to start or stop the existing local proxy without opening the app. Metadata: `versionName 1.11.3`, `versionCode 59`.

No data migration is required. Configure and successfully start the proxy once inside the app before using the tile. The saved runtime can then be reused when relevant network settings remain compatible.

## Highlights

- Add the **TgWsProxy** system tile to start and stop the local proxy with one tap.
- The tile shows an active state only after the frontend has successfully started.
- Missing or changed configuration produces visible feedback rather than opening the app implicitly.
- A simplified monochrome icon is designed for the small Quick Settings tile.

## Changes

### Added

- Android Quick Settings tile with English and Russian names and status text.
- Privacy-conscious tile diagnostic events: `TILE_TAP`, `TILE_START_REQUESTED`, `TILE_STOP_REQUESTED`, and `TILE_START_REJECTED`.
- Regression tests for tile state, duplicate taps and reuse of saved proxy configuration.

### Changed

- Starting from the tile reuses the last successfully saved runtime when the network profile, route policy and frontend configuration remain valid.
- Automatically updated Worker health diagnostics do not by themselves invalidate an otherwise suitable saved configuration.

### Fixed

- A false `CONFIG_CHANGED` rejection that could prevent tile starts even when the proxy worked from the main app.
- Release of the duplicate-tap gate following an early foreground-service startup failure.
- SOCKS5 reports a running frontend only after a successful `start`.

## Installation and updating

Requires Android 8.0+ on ARM64 (`arm64-v8a`). Once published, download the signed `TgWsProxy-Android-v1.11.3-arm64-v8a.apk` from [GitHub Releases](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.3).

Install over an existing official release signed by the same key without uninstalling to preserve app settings. The final signed v1.11.3 APK upgrade still needs post-build verification. Downgrading while retaining app data is not guaranteed because Android enforces `versionCode`.

To add the tile, open Android's Quick Settings editor and drag **TgWsProxy** into the panel. Perform initial setup in the app. The tile controls only the local service; it does not change Telegram proxy settings or create a VPN. The in-app update screen links to official GitHub Releases; it does not automatically install APKs.

## Verification

- [PR #110](https://github.com/Regstar2/tg-ws-proxy-android/pull/110): Windows CI, Android unit tests/debug build, and Worker transport regression — PASS for the Quick Settings feature changes.
- Xiaomi 11 Lite 5G NE / Android 14 (HyperOS): real-device logs confirm tile start, stop and restart with MTProto frontend entering `RUNNING`.
- One measured run reached `RUNNING` 169 ms after `TILE_TAP` and 256 ms after a subsequent tap; these are device-specific measurements, not a general performance guarantee.
- Tag-specific `release.yml` must still verify release metadata, signing and SHA-256 of the final v1.11.3 APK before the published artifact can be considered verified.

## Known issues

- Flowseal Legacy WebSocket remains experimental and may fail on networks that restrict persistent Cloudflare connections. HTTPS Chunk Relay depends on Cloudflare/Durable Objects and may be slower than direct transport.
- A missing or outdated saved configuration cannot be started from the tile; changing network, route settings or an AWG profile may require a fresh app start.
- The full OEM, reboot and network-change matrix has not been verified for the final signed v1.11.3 APK.

## Assets
