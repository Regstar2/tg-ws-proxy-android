# TgWsProxy Android v1.11.8 — обновления из приложения и исправления надёжности

**Русский** · [English](v1.11.8_EN.md)

## О релизе

v1.11.8 — совместимый patch-релиз TgWsProxy Android. Новые функции маршрутизации не добавляются: обновление объединяет уже реализованную проверяемую установку APK, улучшения обработки Fake TLS-отказов, исправление плитки Quick Settings и сообщения о занятом порту.

Метаданные: `versionName 1.11.8` · `versionCode 64` · Android 8.0+ · `arm64-v8a` · `io.github.regstar2.tgwsproxy`. 12 ноября 2026 года собран и проверен подписанный локальный кандидат APK; владелец подтвердил успешную ручную проверку работы приложения и обновления. Подробный протокол отдельных device-сценариев не приложен. Переход с v1.11.7 выполняется поверх приложения при совпадающей подписи без удаления пользовательских данных.

## Главное

- APK можно скачать в самом TgWsProxy и передать штатному установщику Android только после проверки файла.
- Ошибочные Fake TLS-рукопожатия не должны сбрасывать сведения об исправно работающем исходящем MTProto-маршруте.
- Плитка Quick Settings выбирает действие по согласованному состоянию frontend, а не по противоречащим друг другу признакам.
- При занятом локальном порту открытое приложение показывает понятную ошибку.

## Изменения

### Добавлено

- **Обновления:** экран загрузки с прогрессом и отменой, проверка официального ARM64 APK (SHA-256, сертификат подписи, имя пакета, версия, ABI/minSdk), передача системному Package Installer только после проверки и согласия пользователя. Предложение обновления при запуске, интервал повторной проверки, возможность отложить напоминание. Silent install не применяется ([#139](https://github.com/Regstar2/tg-ws-proxy-android/issues/139), [PR #144](https://github.com/Regstar2/tg-ws-proxy-android/pull/144)).
- **Диагностика Fake TLS:** классификация неверных первых записей, отдельный счётчик отклонённых рукопожатий, выборочное логирование повторяющихся отказов ([#138](https://github.com/Regstar2/tg-ws-proxy-android/issues/138), [PR #145](https://github.com/Regstar2/tg-ws-proxy-android/pull/145)).

### Изменено

- Стартовое предложение обновления запускает скачивание напрямую; при необходимости получения разрешения на установку приложение открывает системные настройки соответствующего источника. Пользователь подтверждает установку в Android; отказ не запускает бесконечный цикл запросов.
- Результаты автоматических проверок GitHub Releases кешируются; ручное обновление списка всегда инициирует новый запрос.

### Исправлено

- **Fake TLS:** отклонённое локальное входящее соединение больше не затирает подтверждённый исходящий маршрут и его последнюю ошибку. Под искусственной нагрузкой уменьшено число повторяющихся строк логов, при этом счётчики сохраняются ([PR #145](https://github.com/Regstar2/tg-ws-proxy-android/pull/145)).
- **Quick Settings:** состояние и действие нажатия выведены из одной модели; при переходах и расхождениях плитка временно недоступна, не показывает ложную активность и не отправляет противоречащий состоянию STOP ([#146](https://github.com/Regstar2/tg-ws-proxy-android/issues/146), [PR #147](https://github.com/Regstar2/tg-ws-proxy-android/pull/147)).
- **Занятый порт:** при подтверждённом `PORT_BUSY` MTProto или SOCKS5 открытое приложение показывает короткое локализованное сообщение с рекомендацией сменить порт. Сообщение не содержит номер порта и не появляется при других ошибках ([#148](https://github.com/Regstar2/tg-ws-proxy-android/issues/148), [PR #149](https://github.com/Regstar2/tg-ws-proxy-android/pull/149)).

## Установка и обновление

Для установки и обновления используйте официальный [релиз v1.11.8](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.8): `TgWsProxy-Android-v1.11.8-arm64-v8a.apk` и файл `.sha256`. Проверяйте SHA-256 опубликованного APK по его собственному файлу контрольной суммы.

Для обновления v1.11.7 → v1.11.8 устанавливайте APK с тем же сертификатом без удаления программы: в противном случае могут быть потеряны настройки, список Worker и AWG/WARP-профили. После установки проверьте прокси и параметры; владелец сообщил об успешной ручной проверке 12.11.2026, однако отдельные логи сохранения каждого параметра не представлены. Старый пакет `com.amurcanov.tgwsproxy` (до смены package ID) не обновляется поверх нового приложения. Два прокси на одинаковом порту одновременно не работают.

Встроенная загрузка требует доступности официальных GitHub Releases/CDN, корректного APK и системного разрешения установки из этого источника. Установку завершает **пользователь в системном диалоге**, а не приложение в фоновом режиме. Если этот сценарий недоступен, используйте ссылку на официальный релиз. Откат на прежний `versionCode` поверх новой версии не проверен; не удаляйте приложение без сохранения важных данных.

## Известные проблемы

- Причина исходного спонтанного потока 11 801 отказов Fake TLS 5 ноября не установлена. Подтверждена защита состояния маршрута и устойчивость к искусственной нагрузке, **не** установлено происхождение тех подключений. #138 закрыт без дальнейшего расследования по решению владельца.
- Владелец подтвердил ручную приёмку v1.11.8, но подробных логов отдельной проверки ошибок сети, отказа в разрешении и каждого сохраняемого параметра не предоставлено; см. [матрицу сценариев](../testing/issue-139-in-app-update-acceptance.md).
- Flowseal Legacy WebSocket остаётся экспериментальным; отдельные сети блокируют долгие WebSocket-сессии. Выпускается только ARM64 APK. Поведение плитки зависит от Android SystemUI.

## Артефакты

Локальный подписанный кандидат `TgWsProxy-Android-v1.11.8-arm64-v8a.apk` и его `.sha256` подготовлены 12 ноября 2026 года. **SHA-256 локального APK:** `1d4e9ae194e5043a949966a1ed07fe37c0a72865ca2fcca89aeb1e852b059746`; сертификат подписи SHA-256: `ae55265059933a7b495bd57bc571d294a1850609f56e89117eddf682faae2c6d` (APK Signature Scheme v2). Размер файла в журнале не зафиксирован. Это значение относится к **локальному кандидату**, а не обязательно к APK из GitHub Release. Для опубликованного APK используйте SHA-256 из фактического `.sha256` asset и проверьте точный tag.
