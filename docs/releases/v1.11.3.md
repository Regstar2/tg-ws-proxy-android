# v1.11.3 — Быстрое управление локальным прокси

**Русский** · [English](v1.11.3_EN.md)

## О релизе

`v1.11.3` — совместимый релиз TgWsProxy Android для Android 8.0+ (`arm64-v8a`). В системные быстрые настройки добавлена плитка для запуска и остановки существующего локального прокси без открытия приложения. Метаданные: `versionName 1.11.3`, `versionCode 59`.

Специальная миграция данных не требуется. При первом использовании настройте и один раз успешно запустите прокси в приложении; затем плитка сможет повторно использовать сохранённую конфигурацию при неизменных сетевых условиях.

## Главное

- Плитка **TgWsProxy** в панели быстрых настроек запускает и останавливает прокси одним нажатием.
- Индикация «Включено» появляется только после подтверждённого запуска frontend, а не при отправке команды.
- Настройки, требующие повторного подтверждения, сопровождаются сообщением; плитка не открывает приложение автоматически.
- Добавлена упрощённая монохромная иконка, рассчитанная на небольшой размер системной плитки.

## Изменения

### Добавлено

- Системная плитка Android Quick Settings с названием и подписями на русском и английском языках.
- События `TILE_TAP`, `TILE_START_REQUESTED`, `TILE_STOP_REQUESTED` и `TILE_START_REJECTED` для диагностики переключения без вывода секретов.
- Регрессионные тесты состояний плитки, повторных нажатий и повторного использования сохранённой конфигурации.

### Изменено

- Для запуска через плитку используется последний успешно сохранённый runtime при совпадении сетевого профиля, разрешённых маршрутов и настроек frontend.
- Автоматически меняющиеся диагностические показатели Worker не должны сами по себе запрещать запуск через плитку.

### Исправлено

- Устранён отказ `CONFIG_CHANGED` в случае, когда прокси из основного приложения запускается, но сохранённый отпечаток несвязанных настроек не совпадает.
- Исправлено освобождение блокировки повторного нажатия при ранней ошибке запуска foreground-сервиса.
- Состояние SOCKS5 frontend подтверждается только после успешного `start`.

## Установка и обновление

Требования: Android 8.0+ и ARM64 (`arm64-v8a`). После публикации скачайте подписанный `TgWsProxy-Android-v1.11.3-arm64-v8a.apk` со страницы [GitHub Releases](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.3).

Для обновления поверх предыдущей официальной release-сборки установите APK без удаления приложения, чтобы сохранить локальные настройки; требуется та же подпись. Проверка обновления именно финальным подписанным APK v1.11.3 должна быть подтверждена после сборки. Откат без удаления данных не гарантируется из-за `versionCode`.

Чтобы добавить плитку, откройте редактор быстрых настроек Android и перетащите **TgWsProxy** в шторку. Первоначальную настройку выполните в приложении. Плитка управляет только локальным сервисом: она не переключает прокси в Telegram и не создаёт VPN. Встроенный экран обновлений открывает официальный GitHub Release, но не устанавливает APK автоматически.

## Проверено

- [PR #110](https://github.com/Regstar2/tg-ws-proxy-android/pull/110): Windows CI, Android unit-тесты/debug-сборка и Worker transport regression — PASS на исходном изменении Quick Settings.
- Xiaomi 11 Lite 5G NE / Android 14 (HyperOS): через плитку подтверждены запуск, остановка и повторный запуск; Logcat показал переход frontend MTProto в `RUNNING`.
- По логам одного испытания: от `TILE_TAP` до `RUNNING` — 169 мс при первом запуске и 256 мс при повторном; это не гарантия скорости для других устройств и сетей.
- Точные релизные метаданные, подпись и SHA-256 финального APK должны проверяться `release.yml` для тега `v1.11.3`. До завершения workflow подписанный релизный APK не считается проверенным.

## Известные проблемы

- Flowseal Legacy WebSocket остаётся экспериментальным транспортом и может не работать в сетях, ограничивающих долгоживущие соединения Cloudflare. HTTPS Chunk Relay зависит от Cloudflare/Durable Objects и может быть медленнее прямого маршрута.
- Плитка не может запускаться с неподтверждённой или устаревшей конфигурацией; после смены сети, маршрутов либо AWG-профиля может потребоваться запуск из приложения.
- Полная матрица OEM, перезагрузки и смены сети для итогового подписанного APK v1.11.3 не проверена.

## Артефакты

Штатный release workflow должен опубликовать два файла после сборки и проверки подписи:

- `TgWsProxy-Android-v1.11.3-arm64-v8a.apk` — Android 8.0+, ARM64.
- `TgWsProxy-Android-v1.11.3-arm64-v8a.apk.sha256` — контрольная сумма фактически подписанного APK.

Размер и SHA-256 указываются только по опубликованным артефактам; до сборки они неизвестны.
