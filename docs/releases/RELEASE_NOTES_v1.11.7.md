# TgWsProxy Android v1.11.7 — настраиваемый порядок маршрутов

`versionName 1.11.7` · `versionCode 63` · планируемый stable · Android 8.0+ / ARM64 (`arm64-v8a`)

v1.11.7 добавляет единый список пяти маршрутов с изменяемым строгим порядком MTProto fallback, исправляет отображение подтверждённого исходящего маршрута и показатели скорости в уведомлении.

[Полное описание на русском](https://github.com/Regstar2/tg-ws-proxy-android/blob/v1.11.7/docs/releases/v1.11.7.md) · [Full release notes in English](https://github.com/Regstar2/tg-ws-proxy-android/blob/v1.11.7/docs/releases/v1.11.7_EN.md)

## Главное

- **Настройки → Маршруты:** одно место для пяти путей. Можно менять местами включённые и выключенные маршруты, сохранять отдельные профили Wi-Fi и мобильной сети и видеть цепочку fallback; настройки применяются к новым MTProto-сессиям без перезапуска.
- **Строгая маршрутизация:** используются только включённые пути сверху вниз. Один активный маршрут не разрешает скрытый резервный путь.
- **Реальный исходящий маршрут:** успешный TCP → AWG отображается как AWG; неудачные локальные рукопожатия больше не стирают последнее подтверждённое подключение.
- **Уведомление:** исправлены счётчики загрузки и отдачи; отображается время установки последнего исходящего соединения — **не ping/RTT**.

## Установка и обновление

После публикации скачайте `TgWsProxy-Android-v1.11.7-arm64-v8a.apk` и соответствующую `.sha256` из [GitHub Release](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.7). Требуется Android 8.0+ и ARM64.

Для обновления поверх v1.11.6 требуется прежний сертификат подписи. Настройки маршрутов мигрируют в упорядоченную модель; фактическую сохранность данных необходимо проверить на финальном APK. Установки со старым `applicationId com.amurcanov.tgwsproxy` — отдельные приложения и не обновляются таким способом.

## Проверено

[CI исправлений](https://github.com/Regstar2/tg-ws-proxy-android/actions/runs/42043647479) на `9d59296f` прошёл. Предыдущий Xiaomi smoke подтвердил TCP → AWG и двусторонний MTProto на более ранней сборке. Финальная проверка подписанного Release APK, обновления с v1.11.6 и скорости/времени подключения на устройстве **ещё не выполнена**.

## Известные проблемы

- Массовые отклонения локальных Fake TLS рукопожатий, обнаруженные в Xiaomi-логе, исследуются в [#138](https://github.com/Regstar2/tg-ws-proxy-android/issues/138).
- Flowseal Legacy WebSocket остаётся экспериментальным.
- Выпускается только APK для ARM64.
