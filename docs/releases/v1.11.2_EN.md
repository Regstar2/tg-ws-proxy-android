# v1.11.2 — Flowseal Worker and redesigned Worker Pool

[Русский](v1.11.2.md) · **English**

## About this release

`v1.11.2` is a compatible patch release of TgWsProxy Android for Android 8.0+ (`arm64-v8a`). It restores an explicit option for original Flowseal Workers and redesigns the Telegram Worker management screen. App metadata: `versionName 1.11.2`, `versionCode 58`.

Flowseal Legacy WebSocket (`/apiws`) is still **experimental and unreliable**. Existing Workers retain HTTPS Chunk Relay as their default; the app does not silently switch protocols. The recommended primary route is unchanged.

## Highlights

- Restored experimental compatibility with original Flowseal Workers using WebSocket `/apiws` rather than Chunk Relay/Durable Objects.
- Redesigned **Settings → Cloudflare → Worker Pool** around one Worker list, explicit transport, connection state and diagnostics.
- Fixed delayed strategy selection feedback: the chosen radio option and summary now update without leaving the screen.
- Worker diagnostics distinguish the selected transport from a basic WebSocket handshake and do not claim that HTTP 101 proves Telegram connectivity.

## Changes

### Added

- Explicit **HTTPS Chunk Relay** and **Flowseal Legacy WebSocket (/apiws)** selection for the legacy single Worker and individual Worker Pool entries. Previous Worker settings and default protocol are preserved.
- Add/import actions, enabled state and details within the unified Worker list.

### Changed

- Consolidated the selected Worker and route status into a single panel. Selection strategy is near the list; DC→IP and media controls are in an expandable section.
- Improved readability for long domains and larger system fonts, reduced dialog clutter and refined Russian UI translations.
- Worker check results now distinguish reachability and protocol compatibility from proven bidirectional MTProto traffic.

### Fixed

- HTTPS Chunk Relay checks no longer interpret an old `/apiws` handshake as confirmation of the configured Worker.
- Changing the selection strategy updates the visible option immediately rather than only after re-entering the screen.

## Installation and updating

Download the signed `TgWsProxy-Android-v1.11.2-arm64-v8a.apk` from [GitHub Releases](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.2). Requires Android 8.0+ on `arm64-v8a`.

With the original release signing key, an upgrade over `v1.11.1` is designed to preserve app-private settings; Worker migration is not required. Do not uninstall the existing app to update it. Installation of the final tagged APK over `v1.11.1` has not been independently verified. Downgrading without removing app data is not guaranteed due to Android versionCode.

The app checks official GitHub Releases and opens the official download page; it does not claim to silently install updates.

## Verification

- [PR #106 CI](https://github.com/Regstar2/tg-ws-proxy-android/pull/106): Windows CI, Android unit tests/build and Worker transport regression passed.
- Android: the owner reviewed the redesigned UI and provided layout and strategy-switching feedback; the corresponding fixes were implemented. Separate final-device verification of the published release APK has not yet been confirmed.
- A complete real-world Legacy WebSocket Telegram messages/media round-trip **has not been verified** on restrictive networks. HTTP 101 alone is not proof of MTProto.
- The tag-specific Release workflow independently checks source CI, APK metadata, signing and SHA-256. Inspect its final result in GitHub Actions.

## Known issues

- **Flowseal Legacy WebSocket is unstable.** Some ISPs restrict long-lived Cloudflare WebSocket connections. Telegram may remain disconnected, and messages or media may fail to send or load. This route is not a guaranteed bypass method.
- **HTTPS Chunk Relay** relies on Cloudflare/Durable Objects, is slower than direct transport and can have slow media transfers. Worker is not the recommended default route.
- A reachability check, protocol handshake or HTTP 101 response **does not establish** working full-duplex MTProto.

## Assets

The Release workflow publishes `TgWsProxy-Android-v1.11.2-arm64-v8a.apk` and `TgWsProxy-Android-v1.11.2-arm64-v8a.apk.sha256`. The checksum is calculated from the actual signed release file, not predetermined. Both files must be attached to the completed GitHub Release.
