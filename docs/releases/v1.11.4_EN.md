# v1.11.4 — Quick Settings, notification, and onboarding fixes

[Русский](v1.11.4.md) · **English**

## About this release

`v1.11.4` is a planned compatible stable patch for TgWsProxy Android on Android 8.0+ / ARM64 (`arm64-v8a`). Candidate metadata: `versionName 1.11.4`, `versionCode 60`. It addresses the Quick Settings tile, foreground notification updates, and onboarding dismissal. Telegram routing and user settings formats are unchanged; no dedicated migration is required.

## Highlights

- A long press on the TgWsProxy Quick Settings tile is routed to the app's main screen; actual Xiaomi/HyperOS SystemUI behavior still requires device verification.
- Unchanged foreground notification content is no longer republished for each metrics sample. The notification behavior was tested with a competing VPN speed notification on Xiaomi / Android 14.
- “Don't show again” now persists when the onboarding dialog is skipped or dismissed, while the guide remains available from Help.

## Changes

### Fixed

- **Quick Settings:** added the `QS_TILE_PREFERENCES` intent handler in `MainActivity`. Reusing an existing activity returns to the main page without toggling the proxy; the short-tap behavior remains unchanged ([#114](https://github.com/Regstar2/tg-ws-proxy-android/issues/114), [PR #116](https://github.com/Regstar2/tg-ws-proxy-android/pull/116)).
- **Foreground notifications:** suppresses duplicate visible presentations, limits changed periodic content to one publication every three seconds, and preserves one notification timestamp per service session. Existing lifecycle behavior and actions remain ([#115](https://github.com/Regstar2/tg-ws-proxy-android/issues/115), [PR #117](https://github.com/Regstar2/tg-ws-proxy-android/pull/117)).
- **Onboarding:** “Don't show again” persists after Done, Skip, or system dismissal. The existing `onboarding_completed` setting is retained for compatibility; users can still reopen the guide from Help ([#118](https://github.com/Regstar2/tg-ws-proxy-android/issues/118), [PR #119](https://github.com/Regstar2/tg-ws-proxy-android/pull/119)).

## Installation and updating

After publication, download `TgWsProxy-Android-v1.11.4-arm64-v8a.apk` from the [release page](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.4). Requires Android 8.0+ on ARM64.

Install it over an existing **official** release signed with the same key without uninstalling to preserve settings. For a fresh installation, configure the MTProto proxy in the app and add the Quick Settings tile manually if needed. The in-app update screen links to official GitHub Releases but does not automatically install the APK. Downgrading to an older `versionCode` without removing data is not guaranteed.

The tile only controls the local service: it does not modify Telegram proxy settings or create a system VPN.

## Known issues

- Xiaomi/HyperOS long-press behavior depends on SystemUI; complete the [device checklist](../testing/quick-settings-long-press.md). A passing manifest test alone does not establish OEM behavior.
- Flowseal Legacy WebSocket remains experimental on networks that restrict persistent Cloudflare connections. HTTPS Chunk Relay depends on Durable Objects and may be slower than a direct connection.
- Starting the service from the tile requires a previously successful compatible configuration. Changing network, route or AWG profile may require starting it from the app. The complete OEM matrix has not been tested.
