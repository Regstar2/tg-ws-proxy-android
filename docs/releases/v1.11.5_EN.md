# v1.11.5 — Fix Quick Settings proxy startup after network changes

[Русский](v1.11.5.md) · **English**

## About this release

v1.11.5 is a planned compatible stable patch for TgWsProxy on Android 8.0+ / ARM64 (arm64-v8a). Metadata: versionName **1.11.5**, versionCode **61**. It fixes Quick Settings startup after network switching and improves tile responsiveness. User settings and the proxy transport format are unchanged; no special migration is required.

## Highlights

- The Quick Settings tile can start an already configured proxy after switching between Wi-Fi and mobile data without a false “Settings changed” warning.
- Every tile start resolves the **current** network and saved route settings instead of reusing an older runtime snapshot.
- The tile promptly displays “Connecting” during preparation without showing ACTIVE before the proxy actually runs.

## Changes

### Changed

- **Quick Settings:** fresh configuration preparation now runs off the tile's main thread. The tile displays a transitional state immediately and only reports ACTIVE after the frontend reaches RUNNING.
- **Diagnostics:** privacy-safe markers distinguish runtime preparation and foreground-notification submission. No endpoints, tokens, or saved configuration values are logged.

### Fixed

- **Startup after changing networks:** old v1/v2 confirmation signatures no longer reject a valid new network/route configuration. The current network and routing policy are rebuilt on each start ([#122](https://github.com/Regstar2/tg-ws-proxy-android/issues/122), [PR #123](https://github.com/Regstar2/tg-ws-proxy-android/pull/123)).
- **Stale runtime safety:** the last-used runtime is not a fallback. Invalid current configuration, frontend port, or MTProto settings produce a controlled rejection. Initial setup still requires one successful in-app startup.

## Installation and updating

**Fresh install:** after publication, download TgWsProxy-Android-v1.11.5-arm64-v8a.apk from the [release Assets](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.5). Requires Android 8.0+ / arm64-v8a. Configure and successfully start the proxy once inside the app, then add the Quick Settings tile through Android's tile editor.

**Update from v1.11.4:** install the official signed APK **over** the existing app without uninstalling it. The release signing identity must match. Data-preserving installation was verified with a release-signed test APK over v1.11.4; installation of the **final v1.11.5 Release APK is not yet verified**. The built-in update checker opens GitHub Releases; it does not install APKs automatically. Android may reject downgrades to a lower versionCode without uninstalling; rollback without data loss is unverified.

The tile controls only the local proxy service. It neither modifies Telegram's proxy settings nor creates a system VPN.

## Known issues

- One successful in-app start is required for initial setup. Invalid new settings still prevent tile startup.
- Quick Settings and notification presentation depend on OEM SystemUI. The full Android/OEM matrix and separate on-device SOCKS5 and AWG/WARP checks for v1.11.5 have not been performed.
- Flowseal Legacy WebSocket remains experimental: Telegram connections, messages or media may fail on networks restricting long-lived WebSocket traffic. HTTPS Chunk Relay can be slower than direct routes.
- Original report [#121](https://github.com/Regstar2/tg-ws-proxy-android/issues/121) stays open until the published APK is checked.
