# v1.11.2 — Flowseal Worker и обновлённый Worker Pool

**Русский** · [English](v1.11.2_EN.md)

## О релизе

`v1.11.2` — совместимый patch-релиз TgWsProxy Android для Android 8.0+ (`arm64-v8a`): возвращает возможность явно выбирать оригинальный Flowseal Worker и обновляет интерфейс Telegram Worker. Версия приложения: `versionName 1.11.2`, `versionCode 58`.

Flowseal Legacy WebSocket (`/apiws`) остаётся **экспериментальным и нестабильным** вариантом. Рекомендуемый прежний HTTPS Chunk Relay сохраняется по умолчанию для всех существующих Worker; автоматического переключения протокола нет. Основной рекомендуемый маршрут приложения не меняется.

## Главное

- Возвращена экспериментальная совместимость с оригинальными Worker по инструкции Flowseal, использующими WebSocket `/apiws` вместо Chunk Relay/Durable Objects.
- Переработан экран **Настройки → Cloudflare → Worker Pool**: единый список Worker, выбранный протокол, статус подключения, диагностика и действия.
- Исправлена задержка обновления стратегии выбора: выбранная радиокнопка и описание меняются без повторного открытия экрана.
- Диагностика Worker учитывает реально выбранный протокол и не считает простой WebSocket handshake подтверждением работы Telegram.

## Изменения

### Добавлено

- Выбор транспорта **HTTPS Chunk Relay** или **Flowseal Legacy WebSocket (/apiws)** для одиночного Worker и для каждого адреса в пуле. Сохранены прежние настройки и протокол по умолчанию.
- Возможность добавлять и импортировать адреса Worker, управлять их состоянием и открывать подробности из единого списка.

### Изменено

- Объединены блоки выбранного Worker и состояния маршрута. Стратегия выбора находится рядом со списком, а DC→IP и media-параметры вынесены в раскрываемый раздел.
- Исправлены длинные подписи и домены при крупном системном шрифте; упрощены диалоги и улучшены русские переводы интерфейса.
- Статусы проверок отличают доступность и совместимость Worker от реального двустороннего MTProto-обмена.

### Исправлено

- Проверка HTTPS Chunk Relay больше не использует результат старого `/apiws` handshake как доказательство работоспособности текущего Worker.
- Выбор стратегии обновляется на экране сразу, а не только после выхода и повторного входа.

## Установка и обновление

Скачайте официальный подписанный `TgWsProxy-Android-v1.11.2-arm64-v8a.apk` из [GitHub Releases](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.2). Требования: Android 8.0+ и `arm64-v8a`.

При использовании оригинальной release-подписи установка поверх `v1.11.1` рассчитана на сохранение данных приложения; отдельная миграция Worker не требуется. Не удаляйте приложение для обновления. Установка поверх `v1.11.1` из финального APK отдельно не проверялась. Откат на более старую версию без удаления данных не гарантирован из-за Android versionCode.

Приложение проверяет официальные GitHub Releases и открывает страницу скачивания. Самостоятельная фоновая установка APK не заявлена.

## Проверено

- CI [PR #106](https://github.com/Regstar2/tg-ws-proxy-android/pull/106): Windows CI, Android unit-тесты/сборка и Worker transport regression — успешно.
- Android: владелец проверил переработанный экран и передал замечания по компоновке и переключению стратегии; замечания исправлены. Отдельная финальная проверка опубликованного release APK ещё не подтверждена.
- Для экспериментального Flowseal Legacy **не подтверждён** полный обмен сообщениями и медиа на сетях с ограничениями. Прохождение проверки HTTP 101 не равно успешному MTProto.
- Сборка, подпись, метаданные APK и SHA-256 для конкретного релизного тега проверяются отдельным workflow публикации. Результат этого workflow необходимо проверить в GitHub Actions.

## Известные проблемы

- **Flowseal Legacy WebSocket нестабилен:** некоторые провайдеры ограничивают долгоживущие WebSocket-соединения через Cloudflare. Telegram может не подключаться; сообщения и медиа могут не отправляться или не загружаться. Этот транспорт не следует считать гарантированным способом обхода блокировок.
- **HTTPS Chunk Relay** зависит от Cloudflare/Durable Objects и остаётся медленнее прямого маршрута; возможна медленная загрузка медиа. Worker не является рекомендуемым основным маршрутом.
- Проверка доступности Worker, совместимости протокола или ответа HTTP 101 **не подтверждает** двустороннюю передачу MTProto.

## Артефакты

Release workflow публикует подписанный APK `TgWsProxy-Android-v1.11.2-arm64-v8a.apk` и файл `TgWsProxy-Android-v1.11.2-arm64-v8a.apk.sha256`. SHA-256 берётся только из фактически собранного файла; заранее не задаётся. Оба файла должны появиться в GitHub Release после успешного workflow.
