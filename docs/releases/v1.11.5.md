# v1.11.5 — Исправление запуска прокси из Quick Settings

**Русский** · [English](v1.11.5_EN.md)

## О релизе

v1.11.5 — планируемый совместимый stable patch для TgWsProxy Android 8.0+ / ARM64 (arm64-v8a). Метаданные: versionName **1.11.5**, versionCode **61**. Обновление исправляет запуск системной плиткой после смены сети и делает реакцию плитки более отзывчивой. Формат пользовательских настроек и транспорт прокси не меняются; отдельная миграция не нужна.

## Главное

- Плитка Quick Settings запускает уже настроенный прокси после перехода Wi-Fi ↔ мобильная сеть без ложного сообщения «Настройки изменились».
- Для каждого запуска используются текущие сохранённые настройки и **актуальный** профиль сети вместо конфигурации прошлого запуска.
- Плитка быстрее показывает переходное состояние «Подключение», не выдавая подготовку за работающий прокси.

## Изменения

### Изменено

- **Quick Settings:** подготовка конфигурации вынесена с главного потока плитки. Статус «Подключение» появляется сразу, а ACTIVE — только когда frontend действительно RUNNING.
- **Диагностика:** появились безопасные отметки времени подготовки конфигурации и передачи foreground-уведомления системе. Они не включают адреса, токены или настройки пользователя.

### Исправлено

- **Повторный запуск после смены сети:** плитка больше не отвергает работающую конфигурацию только из-за старой v1/v2-подписи. Параметры сети и маршрута пересчитываются при каждом нажатии ([#122](https://github.com/Regstar2/tg-ws-proxy-android/issues/122), [PR #123](https://github.com/Regstar2/tg-ws-proxy-android/pull/123)).
- **Устаревшие параметры:** сохранённый runtime прошлого запуска не используется как запасной путь; некорректные текущие настройки, порт или MTProto-конфигурация дают контролируемый отказ. Первый запуск из плитки по-прежнему требует хотя бы одного успешного запуска через приложение.

## Установка и обновление

**Новая установка:** после публикации скачайте TgWsProxy-Android-v1.11.5-arm64-v8a.apk из [Assets](https://github.com/Regstar2/tg-ws-proxy-android/releases/tag/v1.11.5). Требуются Android 8.0+ и arm64-v8a. Настройте и один раз успешно запустите прокси в приложении, затем добавьте плитку через редактор быстрых настроек.

**Обновление с v1.11.4:** установите официальный APK **поверх** старой версии, без удаления приложения; подпись релиза должна совпадать. Сохранение данных подтверждено при установке подписанного тестового APK поверх v1.11.4; установка именно **финального v1.11.5 Release APK ещё не проверена**. Встроенный экран обновления открывает GitHub Releases, но не устанавливает APK автоматически. Откат на более низкий versionCode без удаления данных может быть запрещён Android; безопасный откат не проверен.

Плитка управляет только локальным сервисом, не меняет настройки прокси в Telegram и не создаёт системный VPN.

## Известные проблемы

- Для самой первой настройки нужен один успешный запуск прокси в приложении; только затем плитка может запускать его самостоятельно. Невалидные новые настройки должны блокировать запуск.
- Поведение Quick Settings и задержка отображения уведомления зависят от SystemUI производителя; полный набор Android/OEM, а также отдельные проверки SOCKS5 и AWG/WARP на устройстве для v1.11.5 не выполнены.
- Flowseal Legacy WebSocket остаётся экспериментальным: в отдельных сетях Telegram может не подключаться или не загружать сообщения/медиа. HTTPS Chunk Relay может работать медленнее прямого транспорта.
- Исходное сообщение об ошибке [#121](https://github.com/Regstar2/tg-ws-proxy-android/issues/121) остаётся открытым до проверки опубликованного APK.
