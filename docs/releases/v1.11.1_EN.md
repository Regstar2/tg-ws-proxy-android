# v1.11.1 — proxy autostart after Android boot

[Русский](v1.11.1.md) · **English**

## About this release

`v1.11.1` is a stable patch release of TgWsProxy Android for Android 8.0+ / `arm64-v8a`.

Metadata: `versionName 1.11.1`, `versionCode 57`.

The main change is optional restoration of the existing local proxy runtime after Android finishes booting. The setting is disabled by default and does not change current behavior until the user explicitly enables it.

## Boot autostart

A **Start automatically when device turns on** switch is available under **Settings → App → Service**.

When enabled:

1. Android delivers `BOOT_COMPLETED`;
2. TgWsProxy checks the stored preference and last proxy configuration;
3. the existing `ProxyService.ACTION_START` path is used;
4. the normal foreground notification infrastructure is reused;
5. no Activity or UI is opened automatically.

The same persisted startup state is reused: local port, runtime config/IPs, pool size, selected frontend, and the related routing settings already consumed by the service.

SOCKS5 with an empty/invalid runtime configuration is skipped safely. Frontends that do not require `last_runtime_ips` are not blocked artificially.

Manually stopping the proxy does not disable the boot-autostart preference; the setting controls only behavior after the next system boot.

## OEM compatibility

Some Android vendors apply additional background/autostart restrictions.

A physical reboot smoke test was confirmed on Xiaomi/HyperOS after enabling the separate system background/autostart permission for TgWsProxy. The application does not attempt to bypass OEM restrictions.

## Diagnostics

Privacy-safe `BOOT_*` events cover:

- receipt of `BOOT_COMPLETED`;
- disabled autostart;
- successful `ACTION_START` request;
- invalid saved-state skip;
- already-running runtime;
- start failure.

Secrets, WARP/AWG keys, tokens, and private runtime configuration are not written to these events.

## Tests

Unit coverage includes:

- default `false`;
- preference persistence;
- disabled → skip;
- enabled + valid config → start;
- enabled + invalid SOCKS5 config → skip;
- frontend start without mandatory runtime IP config;
- repeated boot delivery;
- shared saved startup configuration round-trip.

A real reboot/device smoke test was completed before release preparation.

## Installation and updating

Download:

`TgWsProxy-Android-v1.11.1-arm64-v8a.apk`

Requirements: Android 8.0+ and `arm64-v8a`.

The official APK uses the same release signature and is intended to update `v1.11.0` without uninstalling the app or losing app-private settings.
