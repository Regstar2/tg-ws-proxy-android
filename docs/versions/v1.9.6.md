# v1.9.6 — Safe Flowseal Media Fix Scope

## Цель версии

Сузить область применения `FLOWSEAL_MEDIA_DC4_FIX`: по умолчанию сохранять исходный SOCKS5 destination в `socks5_transparent`, не переписывать все media/CDN в DC4 молча.

## Что входит

- Режимы destination: `PRESERVE_ORIGINAL_DST` (default), `FLOWSEAL_DC_MAP`, `EXPERIMENTAL_FORCE_MEDIA_DC4` (legacy pref `flowseal_media_dc4_fix`).
- Experimental media DC4 fix применяется только при `@flowseal_media_fix_enabled=1` **и** media/CDN route **и** выбранном experimental mode.
- Flowseal DC→IP preset включает только `FLOWSEAL_DC_MAP`, не experimental media fix.
- Неизвестные Telegram IPv6/CDN без DC mapping: `route_decision=blocked_or_failed`, `reason=telegram_ipv6_unknown_dc_no_mapping`; TCP passthrough только если политика разрешает `tcp_fallback`.
- Удалён bootstrap unknown CDN → DC4 worker.
- Логи experimental: `experimental_flowseal_dc4_force=true`, `warning=transparent_dst_rewrite_may_break_media`.
- A/B метрики в proxy status: `destination_mode_stats` (sessions, zero_down, avg_duration_ms, close_reason, media_fix_applied).

## Что не входит

- Удаление `FLOWSEAL_MEDIA_DC4_FIX` / legacy pref.
- Изменения worker endpoint pool, WS preconnect (остаётся disabled), критерия `first_packet_sent_to_worker=true`.

## Ручное тестирование

- Default: media IPv6/CDN → `destination_mode=PRESERVE_ORIGINAL_DST`, `flowseal_media_fix_applied=false`.
- Experimental mode + enabled flag: media → DC4 IP, warning в логах.
- `2a0a:f280:...` без mapping → blocked (или tcp fallback по политике), не worker DC4 rewrite.
- Flowseal DC preset → `FLOWSEAL_DC_MAP`, media fix off.
- Diagnostics: destination mode stats после нескольких сессий.

## Критерии готовности

- Media fix не применяется молча ко всем media/CDN.
- Experimental fix включается вручную и сравнивается по метрикам.
- Worker pool / first-packet route success без изменений.
