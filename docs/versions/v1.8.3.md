# v1.8.3 — Diagnostics Screen

## Goal

Visual route diagnostics screen built on Route Probe Core (v1.8.2) and Runtime Route Truth (v1.8.1).

## In scope

- Full-screen **Route diagnostics** with probe result cards
- Actions: Check all, Direct, Worker, Cloudflare, network, Telegram
- Loading, empty, and error states
- Expandable step details per card
- Read-only runtime route block
- Navigation from main screen and Settings → App → Diagnostics
- `DiagnosticsViewModel` + `RouteProbeUiMapper`
- Version `1.8.3` (`versionCode` 39)

## Out of scope

- Export report, persistent logs, Worker Pool, auto route switching from probe results.

## Constraints

- UI → ViewModel → `RouteDiagnosticsRepository` → `RouteProbeRunner`
- Probe does not change Go `activeRoute`

## Manual testing

Open diagnostics, run Check all, verify cards and logcat lines; confirm active route unchanged after probe.
