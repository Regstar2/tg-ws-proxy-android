# v1.10.4 - MTProto Runtime Adapter Interface

## Goal

Create a minimal adapter boundary between the Android app and a future MTProto
runtime without importing native source, changing Gradle native build, or
starting a fake runtime.

## Preconditions

- v1.10.3 is complete.
- `docs/architecture/mtproto-runtime-import-plan.md` documents
  `READY_TO_IMPORT` for a build probe only, while route integration remains
  limited.

## In Scope

- Add `MtProtoRuntimeAdapter` with start/stop/state operations.
- Add runtime state/result/error models.
- Add `MtProtoRuntimeConfig` and mapper from `MtProtoProxyConfig`.
- Add masked diagnostics/log fields for runtime config.
- Add `UnsupportedMtProtoRuntimeAdapter` that validates config and returns
  `UNSUPPORTED` instead of starting a runtime.
- Add unit tests for unsupported behavior, config mapping/masking, invalid
  config, and SOCKS5 default behavior.

## Out of Scope

- Native runtime source.
- Gradle native build integration.
- Route integration.
- UI changes.
- SOCKS5 runtime behavior changes.

## Adapter Contract

`MtProtoRuntimeAdapter`:

- `start(MtProtoRuntimeConfig): MtProtoRuntimeStartResult`
- `stop(): MtProtoRuntimeStopResult`
- `getState(): MtProtoRuntimeState`

States:

- `STOPPED`
- `STARTING`
- `RUNNING`
- `FAILED`
- `UNSUPPORTED`

Error codes:

- `NATIVE_LIBRARY_MISSING`
- `INVALID_CONFIG`
- `PORT_BUSY`
- `START_FAILED`
- `STOP_FAILED`
- `UNSUPPORTED_RUNTIME`

## Manual Testing

No runtime behavior changed in this adapter-only version.

Before any native MTProto implementation:

1. Verify `MTPROTO_EXPERIMENTAL` still fails closed when native runtime is
   absent.
2. Verify SOCKS5 remains the default frontend for fresh/existing users.
3. Verify current SOCKS5 start/stop/reconnect and direct, worker, cf_proxy, tcp
   routes on mobile and Wi-Fi.

## Status

LIMITED:

- Adapter boundary exists, but no native MTProto runtime is integrated.

UNSUPPORTED:

- `UnsupportedMtProtoRuntimeAdapter` returns `UNSUPPORTED_RUNTIME` for valid
  config and `INVALID_CONFIG` for invalid config.

READY_TO_IMPORT_FOR_BUILD_PROBE:

- v1.10.3 permits a minimal, disabled/guarded native build probe.

LIMITED_ROUTE_INTEGRATION:

- The selected Rust runtime still has no shared route backend or route hook.
