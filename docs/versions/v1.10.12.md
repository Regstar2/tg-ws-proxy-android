# v1.10.12 - Publication Prep and Main Screen Cleanup

## What changed

- MTProto Proxy remains the default frontend on shared port `1443`.
- Main screen metrics no longer show Worker Pool state. Worker Pool stays in
  settings and diagnostics.
- Removed leftover main-screen strings for Worker Pool and expandable metrics.
- Removed visible `experimental` wording from MTProto-facing report text and
  Worker media DC4 UI labels.
- Added Russian strings for MTProto Fake TLS fields and diagnostics.
- Runtime log collection now defaults to off. Persistent file logs remain
  opt-in.
- README was rewritten around the current local state: MTProto/CF Proxy works on
  mobile and Wi-Fi, while Worker Pool is still slow.
- README screenshots were replaced with the current files from
  `docs/assets/screenshots/`.
- Local `artifacts/` and `runtime-logs/` contents were removed; `.gitignore`
  already keeps logs, keys, env files and local notes out of Git.

## GitHub comparison

The local tree is ahead of the published `Regstar2/TgWsProxy_Android` main
branch. The README now calls out the large unpublished work instead of
presenting the project as the older SOCKS5-only Android proxy.

## Known issue

Worker Pool is not ready as the default route. The UI and diagnostics are useful
for debugging it, but route startup/fallback is still too slow in real use.

## Verification target

- `.\gradlew.bat assembleDebug`
- `cd native\tgwsproxy && go test ./...`
- APK install on Android device
