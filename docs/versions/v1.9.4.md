# v1.9.4 — Worker Pool UI Polish

## Цель версии

Сделать Worker Pool понятным и удобным для обычного использования без изменения сетевой логики (health check, failover, selection strategies).

## Что входит

- Структурированный экран Worker Pool (summary, strategy, runtime state, worker list, actions).
- UI-модели и `WorkerPoolUiStateMapper` для read-only отображения состояния.
- Компактный worker status на главном экране и в Diagnostics.
- Улучшенные карточки worker, формы, confirmation dialogs, строки EN/RU.
- Persistent logs для UI-действий (без raw URL).
- Unit-тесты mapper logic.

## Что не входит

- Новые selection strategies, weighted balancing, worker groups, import/export.
- Изменения `WorkerFailoverResolver`, `WorkerHealthCheckRunner`, Go routing.

## Архитектурные ограничения

- UI → repository / existing use cases; Composable не выполняет сетевую логику.
- `RouteRuntimeState` — источник runtime truth для read-only блоков.

## Файлы и модули

- `app/.../worker/WorkerPoolUiModels.kt`, `WorkerPoolUiStateMapper.kt`, `WorkerPoolSettingsUi.kt`, `WorkerPoolUiLogger.kt`
- `app/.../MainActivity.kt`, `CloudflareSettingsUi.kt`, `ProxyConnectionMetricsCard.kt`
- `app/.../diagnostics/DiagnosticsScreen.kt`
- `app/src/main/res/values/strings.xml`, `values-ru/strings.xml`
- `app/src/test/.../WorkerPoolUiStateMapperTest.kt`

## План реализации

1. UI-модели и mapper из repository + `RouteRuntimeState` + failover snapshot.
2. Переработка `WorkerPoolSettingsScreen`.
3. Интеграция main screen + Diagnostics.
4. Строки, docs, тесты, gradle verify.

## Ручное тестирование

- Worker Pool screen: summary, strategy, markers, empty/no-enabled/invalid states.
- Add/edit/delete/enable/disable/select/check worker.
- Failover scenario: selected ≠ runtime worker.
- Masked URLs, light/dark theme, rotation.

## Критерии готовности

- Сборка успешна; proxy-сценарий не сломан.
- Все пользовательские строки в ресурсах; URL маскируются.
- UI не меняет routing/health/failover logic.

## Риски

- Большой объём UI-строк; возможны пропущенные ключи локализации.
- MainActivity остаётся composition root (без отдельного ViewModel).
