# v1.11.8 — безопасные обновления и исправления Android

## Цель

Подготовить совместимое обновление TgWsProxy Android на основе уже объединённых в `main` изменений после v1.11.7. Главный сценарий — рабочий локальный Telegram MTProto-прокси без потери пользовательских настроек.

## Входит в версию

- #139 / PR #144: загрузка официального ARM64 APK из приложения, проверка хеша, сертификата, package ID, версии и совместимости, затем передача системному установщику Android; запуск проверки обновлений и уведомления.
- #138 / PR #145: изоляция ошибочных входящих Fake TLS-рукопожатий от состояния исходящего маршрута, категоризация и сэмплирование отказов, диагностические счётчики.
- #146 / PR #147: согласованное отображение и обработка нажатия плитки Quick Settings.
- #148 / PR #149: локализованное короткое сообщение о подтверждённом конфликте локального порта.
- Согласование метаданных `versionName 1.11.8` / `versionCode 64` и RU/EN документации.

## Не входит в версию

- Новые сетевые маршруты, изменение принципа fallback или системы VPN.
- Автоматическая фоновая установка APK без участия пользователя.
- Выдача неподтверждённой причины исходного Fake TLS reconnect storm за исправленную.
- Расширение поддерживаемых ABI за пределы `arm64-v8a`.
- Рефакторинг или расширение релизной инфраструктуры без обнаруженного blocker.

## Совместимость

Android 8.0+ (`minSdk 26`), ARM64, `applicationId io.github.regstar2.tgwsproxy`. Поддерживаемый путь — установка поверх v1.11.7 с тем же сертификатом подписи, без удаления данных. До v1.11.6 использовался другой package ID; автоматическая миграция с него не заявлена.

## Проверки перед выпуском

1. CI на точном итоговом commit и `scripts/ci.ps1`, `scripts/audit-release.ps1`, `scripts/release.ps1 -Version v1.11.8 -PreflightOnly`.
2. Подписанный Release APK: подпись, `applicationId`, `versionCode 64`, `versionName 1.11.8`, SHA-256 и содержимое двух assets.
3. Установка поверх опубликованного v1.11.7 без очистки данных; сохранность маршрутов Wi-Fi/mobile, Worker, AWG/WARP и локального порта.
4. На устройстве: обновление через приложение с системным подтверждением, отказ/повтор разрешения установки, ошибки загрузки/отмена и проверка защиты от неподходящего APK.
5. На устройстве: плитка QS (RUNNING/STOPPED/переходы), ошибка занятого порта, реальная двусторонняя передача Telegram и отсутствие деградации от ошибочных Fake TLS входов.

Все невыполненные пункты остаются NOT_RUN. Известные результаты предыдущих commits не заменяют тест итогового APK.

## Риски

- У #139 есть подтверждённый Xiaomi smoke главного пути через подписанный debug → published v1.11.7, но нет полной матрицы из двух Release APK и отрицательных сценариев.
- Источник самопроизвольных Fake TLS reconnect 2026-11-05 не атрибутирован; #138 закрыт по решению владельца после проверки mitigation, не как доказательство устранения первопричины.
- Проверка плитки зависит от Android SystemUI/прошивки.
- Подписанный релиз публикуется только из проверенного неизменяемого tag после решения GO по [чек-листу](../releases/RELEASE_CHECKLIST.md).
