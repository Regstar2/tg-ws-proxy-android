# Cloudflare Worker setup

Этот путь сохранён для совместимости со старыми ссылками.

Актуальная документация для `v1.11.0`, включая:

- Telegram `cf_worker_ws` через HTTPS chunk relay + Durable Objects;
- standalone provisioning Worker для WARP/AWG;
- пользовательские provisioning Workers;
- три встроенных provisioning Workers проекта;
- порядок bootstrap для автоматического создания WARP-профиля;

находится в [`docs/cloudflare-worker.md`](../cloudflare-worker.md).
